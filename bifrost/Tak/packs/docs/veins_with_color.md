### ***veins_with_color***
Generate veins with vertex color property. (R: Primary, G: Secondary, B: Tertiary) <br />

***
## Input
<span style="color:#90A3F4">***mesh***</span>
<br />The base mesh that veins growth on.

<span style="color:#90A3F4">***start_point***</span>
<br />Root position that starts veins from.

## Output
<span style="color:#90A3F4">***color_set***</span>
<br />Name of the color set. It should have RBG channel. (not RGBA)
