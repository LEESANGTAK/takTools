### ***split_LR_target***
Generate left and right target meshes with source and target mesh. It is useful for facial rigging task. <br />

***
## Input
<span style="color:#90A3F4">***source***</span>
<br />The base mesh. That is not deformed.

<span style="color:#90A3F4">***target***</span>
<br />The target mesh. That is sculpted expression.

## Output
<span style="color:#90A3F4">***target_L***</span>
<br />Left target mesh.

<span style="color:#90A3F4">***target_R***</span>
<br />Right target mesh.
